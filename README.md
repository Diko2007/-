Сервис сравнения тарифов — СРО №17
Выполнил: Мухаметов Дияр
Группа: ИС 25-22
Описание проекта
Учебный веб-сервис для просмотра, фильтрации и сравнения мобильных тарифов. Пользователь может выбирать оператора, задавать максимальную цену и минимальные объёмы интернета и минут, сортировать тарифы и сравнивать выбранные варианты.
Важно: тарифы в проекте демонстрационные и не являются подтверждёнными актуальными предложениями операторов.

Функциональность
- Каталог тарифов.
- Фильтрация по оператору, цене, интернету и минутам.
- Сортировка по цене, объёму интернета и минутам.
- Сравнение двух и более тарифов в таблице.
- Расчёт стоимости за год.
- Проверка числового ввода.
Технологии
- HTML
- CSS
- JavaScript
Проект состоит из одного файла index.html. Дополнительные библиотеки и сервер не требуются.
Запуск
1. Скачайте или скопируйте файл index.html в папку проекта.
2. Откройте папку и дважды нажмите на index.html, чтобы запустить сайт в браузере.
Запуск через VS Code
1. Откройте папку проекта в Visual Studio Code.
2. Откройте index.html.
3. При желании установите расширение Live Server.
4. Нажмите правой кнопкой мыши по index.html и выберите Open with Live Server.
Как проверить работу
1. Убедитесь, что в каталоге отображаются карточки тарифов.
2. Введите максимальную цену, например 4000, и нажмите «Найти тарифы».
3. Установите минимальный интернет или количество минут и проверьте результаты.
4. Выберите сортировку.
5. Нажмите «Сравнить» на карточках двух тарифов — должна появиться таблица сравнения.
6. Проверьте стоимость за год: она рассчитывается как месячная цена, умноженная на 12.
7. Введите отрицательное число в фильтр и нажмите «Найти тарифы» — сайт должен показать ошибку ввода.
